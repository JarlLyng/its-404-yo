FLAC on the SP-404 MkII: convert FLAC to 16-bit WAV

Import from the SD card doesn’t read FLAC at any bit depth, so a pack of .flac files comes back as “Unsupported FILE”. There are two ways round it. Import the files through Roland’s SP-404MK2 App, which does read FLAC, or convert them to 16-bit WAV and import from the card as usual.

Does the SP-404 MkII read FLAC?

Not from the card. Roland’s rule for SD-card import is 16-bit linear WAV, AIFF or MP3, and FLAC isn’t on it. FLAC is on the list for the SP-404MK2 App, Roland’s companion app for the computer, along with M4A (ALAC and AAC on the Mac version). Roland has verified 16 and 24-bit FLAC at rates up to 192 kHz that way, and the unit converts each file to 48 kHz and 16-bit as it comes in.

App or conversion

The app is built around loading samples onto pads inside a project, so it suits a handful of files you want on pads now. Converting suits a whole pack that you want on the card as files, or a library you also use somewhere else. A 16-bit WAV imports by either route, so converting once leaves both open.

Check the bit depth first

FLAC can be 16 or 24-bit, and converting it to WAV changes the container, not the depth, unless you ask for that too. A converter that keeps the source’s depth turns a 24-bit FLAC into a 24-bit WAV, which is still outside the card’s 16-bit rule. Set the output to 16-bit, whatever tool you use.

To see what a file is on a Mac, run afinfo on it in the Terminal. It comes with macOS. For a 24-bit FLAC at 96 kHz the line to read looks like this.

$ afinfo kick.flac
Data format:     2 ch,  96000 Hz, flac (0x00000003) from 24-bit source, 4608 frames/packet

Is converting FLAC to WAV lossless?

Decoding FLAC is exact, so a 16-bit FLAC becomes a 16-bit WAV with the very same samples. A 24-bit FLAC loses its lowest 8 bits on the way to 16-bit. That is the same reduction the SP-404 MkII makes to every sample it imports, since it runs at 16-bit inside, so the unit would have done it anyway.

The target

CodecLinear PCM WAV (from FLAC)
Bit depth16-bit, set it even when the FLAC is 24-bit
Sample rate48 kHz, the unit’s own rate (or 44.1 kHz)
ChannelsMono / stereo preserved

Convert a folder of FLAC with ffmpeg

If you’re comfortable in the Terminal, ffmpeg does it well. One file is

ffmpeg -i kick.flac -c:a pcm_s16le -ar 48000 kick.wav

and every FLAC in the current folder, written as WAV to a new folder called wav, is

mkdir -p wav
for f in *.flac; do
  ffmpeg -i "$f" -c:a pcm_s16le -ar 48000 "wav/${f%.flac}.wav"
done

pcm_s16le is what makes the output 16-bit, and -ar 48000 sets 48 kHz. It works on one folder at a time, so a pack with subfolders needs a run in each.

Or convert the whole pack in one drag

It’s 404, yo! reads FLAC alongside WAV, AIFF, MP3 and M4A. Drop the pack folder in and each FLAC is listed as “FLAC → WAV”, with “96 kHz resampled” beside it where the rate changes too. It converts them to 16-bit WAV at 48 or 44.1 kHz, copies the files that already import untouched, and writes everything in the same folder structure. It runs offline, and your samples never leave your Mac.
